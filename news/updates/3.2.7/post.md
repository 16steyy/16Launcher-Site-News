## Что нового

В этом обновлении мы добавили систему зеркал для повышения стабильности загрузки обновлений и оповещений.

Теперь, если GitHub временно недоступен, доступ к нему ограничен или загрузка завершается ошибкой, лаунчер автоматически использует наше зеркало. Это позволяет продолжать получать обновления даже при проблемах с прямым подключением к GitHub.

# Добавлено

## - Зеркало для оповещений

В связи с тем, что у некоторых пользователей могут возникать трудности с доступом к GitHub без использования VPN, мы добавили альтернативный источник для получения оповещений.

Благодаря этому лаунчер может продолжать получать необходимую информацию даже в случае временной недоступности GitHub.

## - Зеркало для автообновлений

Автообновления лаунчера используют GitHub для получения новых версий. Чтобы сделать процесс обновления более стабильным и доступным, мы добавили резервное зеркало для скачивания релизов.

Лаунчер работает по следующему принципу:

1. Сначала лаунчер пытается скачать обновление непосредственно с GitHub.
2. Если загрузка с GitHub не удаётся, лаунчер автоматически переключается на наше зеркало.
3. После загрузки файл проходит проверку криптографической подписи.
4. Только после успешной проверки обновление может быть установлено.

Таким образом, зеркало является **резервным источником загрузки**, а не заменой GitHub.

## - Криптографическая подпись и защита от подмены файлов

Безопасность обновлений для нас не менее важна, чем их доступность. Поэтому использование зеркала не означает, что скачанному файлу можно безоговорочно доверять.

Релизы подписываются с использованием механизма криптографической подписи Tauri. Перед установкой лаунчер проверяет подпись загруженного обновления и убеждается, что файл соответствует ожидаемому релизу.

Проверка выполняется независимо от источника загрузки — как при скачивании непосредственно с GitHub, так и при использовании нашего зеркала.

Если файл был изменён, повреждён или его подпись не соответствует ожидаемой, проверка не пройдёт и такое обновление не будет установлено.

Таким образом, даже при использовании зеркала лаунчер дополнительно проверяет подлинность обновления непосредственно перед его установкой.

## - Открытый скрипт синхронизации зеркала

Для большей прозрачности мы публикуем актуальную версию скрипта, который используется сервером для синхронизации релизов.

Актуальная версия скрипта находится в открытом репозитории. Файл автоматически обновляется в репозитории при изменении версии скрипта на сервере, поэтому опубликованный файл соответствует актуальной версии, используемой зеркалом.

Сам скрипт предназначен для синхронизации уже опубликованных релизов и не используется для их сборки или изменения содержимого файлов.

# *Подметим!*

Релизы собираются **только через GitHub Actions**.

`api.16-launcher.ru/releases/` — наше зеркало для скачивания релизов на случай, если GitHub недоступен или загрузка с него невозможна.

Файлы на зеркало копируются **без изменений**. Зеркало не собирает релизы самостоятельно и не изменяет содержимое опубликованных файлов.

При этом каждый загруженный файл дополнительно проверяется лаунчером с помощью криптографической подписи. Поэтому источник загрузки не влияет на проверку подлинности обновления.

**GitHub остаётся основным источником релизов, а зеркало используется только как резервный вариант.**

Мы также открыто публикуем актуальный скрипт синхронизации зеркала. При его изменении на сервере новая версия автоматически обновляется в репозитории, что позволяет в любой момент ознакомиться с текущей логикой работы синхронизации.
